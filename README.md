A front-page image summing up Saturday 21 November 2026 in 55 stories across 7 regions: COP31 in overtime in Antalya, three Houthi missiles downed over Riyadh, a magnitude 6.8 quake in Peru, the AI sell-off on Wall Street, and the Trump–Xi–Putin summit in Shenzhen. Every story was checked against the day's reporting; the image is drawn from `stories.json`.

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to `/output/entry.png`.
